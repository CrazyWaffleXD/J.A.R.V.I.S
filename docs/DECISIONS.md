# Решения по архитектуре

Append-only лог. Существующие записи не редактируются и не удаляются:
изменение решения оформляется новой записью с новой датой.

## 2026-10-30 — Лицензия GPL-3.0-only

**Решение:** Проект распространяется под GPL-3.0-only.

**Причина:** Пользователь хочет copyleft. MIT/Apache-2.0 зависимости совместимы
односторонне.

## 2026-10-30 — Команды как отдельные крейты

**Решение:** Каждая команда — отдельный крейт в `commands/*`, зависящий от
`jarvis-core` по path.

**Причина:** Будущий вынос в dylib (libloading) без рефакторинга ядра.

## 2026-10-30 — LLM вне ядра

**Решение:** LLM не входит в ядро, а подключается отдельным плагином позже.

**Причина:** Ядро должно работать офлайн и без тяжёлых зависимостей.

## 2026-10-30 — TTS на стороне пользователя

**Решение:** Синтез речи не реализуется в проекте, мы только плеер (rodio).

**Причина:** Не тащим синтез речи в open-source проект.

## 2026-10-30 — Заметки в JSON, не SQLite

**Решение:** `note` хранит заметки в JSON-файле.

**Причина:** MVP, нет смысла тянуть rusqlite ради десятка заметок.

## 2026-10-30 — Память между сессиями агента

**Решение:** Контекст между сессиями агента передаётся через `STATE.md`,
`TASKS.md` и `DECISIONS.md`, а не перечитыванием всего репозитория.

**Причина:** Экономия токенов и сохранение контекста.

## 2026-10-30 — Целевые платформы v0.1

**Решение:** Поддерживаемые платформы v0.1 — Linux и Windows.

**Причина:** Остальные платформы не тестируются и не заявляются.

## 2026-10-31 — Path-зависимость команд к ядру

**Решение:** В `crates/commands/*/Cargo.toml` использовать
`jarvis-core = { path = "../../jarvis-core" }` (не `../..`).

**Причина:** Крейты команд лежат в `crates/commands/<name>/`, корень репо —
виртуальный workspace-манифест без пакета. `../..` даёт путь в `crates/`,
где пакета `jarvis-core` нет; оттуда же `../../crates/jarvis-core` вёл бы в
несуществующий `crates/crates/jarvis-core`.

## 2026-10-31 — Набор команд v0.1

**Решение:** open, weather, volume, note (не time).

**Причина:** SPEC v0.1 перечисляет именно эти четыре.

## 2026-10-31 — rust-version в workspace

**Решение:** `rust-version = "1.75"`.

**Причина:** В ТЗ bootstrap было 1.75; агент поставил 1.74 — вернули к 1.75.
