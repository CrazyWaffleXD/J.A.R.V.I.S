# AGENTS.md

## Что за проект

Лёгкий модульный ассистент jarvis на Rust. Ядро + команды-крейты.
Не "фулл ИИ". Платформы v0.1: Linux, Windows. Лицензия GPL-3.0-only.

## Порядок чтения перед работой

1. `docs/SPEC.md` — что строим
2. `docs/STATE.md` — что уже сделано и что дальше
3. `docs/TASKS.md` — чеклист v0.1
4. Код — только тот, что нужен по задаче

## Правила обновления памяти

**В НАЧАЛЕ сессии:** прочитай `STATE.md` и `TASKS.md`, не читай
остальной код без нужды.

**В КОНЦЕ сессии:** обнови `STATE.md` (готово / в работе / проблемы /
следующий шаг / важное для следующей сессии) и `TASKS.md` (чекбоксы).
Новые архитектурные решения — в `DECISIONS.md` (append-only, старые
записи не редактируются). Ничего не выдумывай, только реально сделанное.

## Соглашения по коду

- Один шаг = один коммит.
- Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`).
- Публичный API `jarvis-core` не менять без записи в `DECISIONS.md`.
- Новые зависимости — только с обоснованием в `DECISIONS.md`.

## Что НЕ делать

- Не тянуть тяжёлые зависимости без записи в `DECISIONS`.
- Не делать `git init` / `git commit` (это делает человек).
